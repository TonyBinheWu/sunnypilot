# Formosa 參考圖版面

本次依使用者提供的「福爾摩沙智慧駕駛介面」整理字體、字重、間距與配色：寬螢幕採左側功能列、中央駕駛視覺、右側 OSM 地圖，使用淺色面板、圓角邊界與藍色選取狀態。文字以既有 Inter 字型搭配系統繁體中文字型呈現，保留深色外觀選項；不使用未授權的 Apple／Tesla 私有字型。

左側入口對應既有駕駛視覺、導航、行車紀錄、應用程式、車況、聲音與設定。聲音與音量只保留選單入口，駕駛視覺下方不再放重複卡片，騰出的空間供場景使用。目前沒有音樂服務連線，因此不顯示假的歌曲、播放進度或媒體狀態。CarPlay、Android Auto、YouTube、Netflix 沒有接入時不顯示為可操作功能。

12.3 吋 **1920×720**、16:9 與 4:3 使用分區。手機及低高度視窗保留精簡底列，設定、導航等工作頁維持完整可用寬度，避免把車載左右分區硬塞到手機。原有繁中搜尋、詳細指南、確認與回讀、全螢幕、視角拖曳、車速縮放、物件辨識及車型外觀保留。淺色 3D 場景的地面及背景改為同一套淺灰色，避免天空淺、地面卻一直黑色的突兀分割。

地圖詳見 [OSM 顯示與 Mapbox 模型導航](../../docs/NAVIGATION_MAPBOX_OSM.zh-TW.md)，錄影資料詳見 [SEI 車況資料](DRIVING_SEI.zh-TW.md)。介面由車機提供，現有 **Formosa 座艙 0.6.0 APK** 可沿用，更新後重新開啟 App；正式 APK 保持不可變。

參考圖的環境建物、號誌狀態、電量、里程及媒體資訊，只有存在實際可靠資料來源時才能顯示。版面不會補造物件位置、燈色或新增車輛控制能力。
