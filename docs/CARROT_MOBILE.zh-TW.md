# carrotpilot 手機操作指南與功能解析

依本倉庫 `carrot-wip` 的程式碼及既有指南整理。清單代表程式提供的功能；實際可用性仍取決於車型、裝置版本、資料來源、瀏覽器與權限。本次未進行實車或實體手機驗證。

## C3X 與 C4 的駕駛畫面與模型

使用支援導航輸入的 eGPU 大模型時，可在座艙「車況與導航 → 行車規劃」查看路線核對結果，以及即將到來的左轉、右轉、分岔、圓環或迴轉。若定位可能落在兩個路段，或轉向提示與路線彎向相反，系統會暫停採用該組導航提示。「模型與跟車協同」規劃器在接近已確認的轉向時會暫停因前車拉遠而額外補速。[場景判讀與硬體配置](PHYSICALAI_VLA.zh-TW.md)

手機瀏覽器與 CarrotAssist 從「工具 → sunnypilot 駕駛模型選擇器」進入。Formosa 座艙從「應用程式 → 工具／診斷」進入。清單包含 carrot-wip 原有模型以及 sunnypilot 的 79 個小模型、25 個大模型。停車並關閉點火後，選擇模型，等到顯示「已儲存，下次開機套用」，再重啟車機。在 C4 同一頁可開啟 PhysicalAI-reason-VLA 4B 與內建主模型的決策比對，由 Chestnut USB 上的 RX 9060 8 GB 執行 VLA。[模型、硬體及驗證說明](SUNNYPILOT_MODELS_AND_SCENE.zh-TW.md)

選擇器會顯示正在處理的檔案。下載時可查看實際接收容量和百分比，總大小未知時會先顯示已接收容量。PhysicalAI 4B 的進度合計兩個權重檔，已驗證的快取也計入已完成容量。進度達到 100% 後，請等候檔案驗證及儲存完成。

同一頁的「C3X／C4 本機駕駛畫面」可選動態 3D、原始鏡頭或模型感知 3D。本機也可由設定中的「駕駛畫面」切換。模型感知顯示道路邊界、標線、路徑及前車。前向影像辨識提供行人和汽機車分類。畫面分別標示可能的道路開口和離線圖資的路口。

「車道置中」與「低速方向燈轉彎」於下次行駛生效。置中需要左右標線都有足夠信心。低速轉彎在時速約 32 公里以下接受駕駛的單側方向燈。駕駛仍需判斷路權、注意號誌與對向車。

現代、起亞及 Genesis 在車輛設定精靈預設使用一般線束與自動偵測。已確認線束接在 ADAS ECU 的 EV6，可直接選該匯流排。Carrot Web 導航的離線地圖可下載台灣、南韓、盧森堡或安道爾的道路圖磚。地圖輸入支援程度依模型而異。

## 車道建圖與多趟比對（研究工具）

更新車機後，網頁及既有 CarrotAssist 0.2.19 可由「工具 → 車道建圖與多趟比對」開啟離線成果。支援 BEV／3D、旋轉／縮放／平移、趟次篩選、來源與品質、版本觀測差異、人工審查 JSON。可看明確標示的合成範例、本機／貼上 JSON，或管理者手動放在 `/data/carrot/mapping` 的成果。資料不自動上傳；審查僅存目前分頁，需匯出保存。

工作站工具擷取模型車道，配合外部已配準位姿建圖；沒有新增 VIO 求解器、訓練權重、完整環景或可控制車輛的高精度地圖。不同路線／視野造成的未觀測不代表道路消失，分散度也不是實測精度。前窄角＋廣角仍需內外參與時間同步；更高精度另需測量／RTK 基準。[完整繁中格式、指令與配套清單](carrot_mapping_zh-TW.md)。

## 錯誤自我診斷與修復（0.2.19）

更新並完整重新啟動車機後，網頁及 APK 可開啟 **工具 → 錯誤自我診斷與修復**。完整車機診斷也可由既有 APK 載入更新後網頁；下述原生離線連線檢查須安裝 [0.2.19 APK](https://github.com/TonyBinheWu/sunnypilot/releases/download/carrot-assist-tw-v0.2.19/CarrotAssist-TW-0.2.19.apk)。

### 自動檢查與結果判讀

網頁請求失敗、工具執行錯誤、頁面程式錯誤或已啟動 Vision 的連線失敗／等待超過 10 秒，會記錄目前分頁最近 12 筆錯誤類型，最長保留 15 分鐘；連續相同錯誤去重，自動檢查最多每 30 秒一次且不在背景分頁啟動。診斷請求自身的失敗不會再觸發診斷循環，也不會重送上一次設定變更。既有影像串流的重連機制繼續運作。

診斷中心讀取當次車機狀態：CAN 有效性／讀取逾時、目前警告、應執行程序是否停止、溫度、可用空間、記憶體、校正、大模型準備／錯誤狀態及 FormosaLink 配對／雲端確認。停車時缺少行車 CAN 或駕駛模型資料可能正常；過期或缺少資料會標為「尚未確認」，不當作健康結果。即使當次 CAN 有效，也不能排除先前間歇斷訊。

「貼上錯誤訊息」可在本機依規則提供檢查方向，涵蓋 CAN、處理逾時、模型、影像、網路與語音權限；這是文字推測，不是已確認的故障原因。沒有相符規則時會請你保留紀錄，不會猜一組車輛參數套用。

### 可以執行的排除操作

| 操作 | 條件與作用 |
|---|---|
| 重新檢查 | 只讀取新的狀態，不更改設定 |
| 重新載入網頁連線 | 需確認；保留已儲存值，尚未送出的表單／回放位置可能遺失；不重送前次寫入 |
| 啟用 Carrot Vision | 僅在目前停用時提供，需確認並由車機重新確認 P 檔、停止且控制關閉，或真正停車熄火的 offroad；讀回驗證開關後，仍需看到新影格才能確認影像恢復 |
| 重新啟動車機 | 僅在程序停止、處理延遲、記憶體偏高或更新待重啟等相關結果時提供，需確認並重新確認停車狀態；送出後先顯示「已請求」，重新連線並檢查後才能判定排除 |
| CAN／車型／HDA 檢查 | 先核對實際線束與車型，再關閉診斷使用工具的「重新執行設定引導」；不自動換匯流排、開雷達或隱藏 CAN 警告 |
| 模型異常 | 使用工具 eGPU／模型卡片原有重試與重新驗證流程；不刪快取、不繞過拒絕或簽章驗證 |
| FormosaLink／校正／空間／溫度 | 依結果提供步驟；不自動開放遠端權限、重新配對、重設校正、刪除錄影或停用保護 |

修復請求為短效、單次使用；逾時、重複點擊或狀態改變時須重新檢查。連線中斷若無法確認結果，不會宣稱已修好，也不會自動重試重啟。請恢復連線再確認目前狀態。

### APK 連不上車機時

0.2.19 可點上方裝置名稱 → **連線自我診斷與修復**；網頁主要頁面載入失敗時，也會出現原生診斷及重新搜尋按鈕。此入口不依賴車機網頁能否開啟，會檢查區域網路 IPv4 介面、以原有唯讀探測驗證選取的 Carrot Web、顯示麥克風權限及裝置端語音服務是否可用，並提供重新搜尋、手動 IP、Wi-Fi 設定、中文語音檢查及完整車機診斷入口。驗證不到服務不等於已確認車機壞掉，也可能是 IP、網段隔離、供電或啟動未完成；語音服務可用不代表 zh-TW 模型已安裝。

關閉、切換到背景或離開 App 會取消原生探測，舊回應不再改動畫面。檢查不自動授權麥克風、不清除 App 資料或帳號、不傳送行車指令。完整診斷需要恢復連線並使用更新後的車機程式。

「顯示／下載診斷報告」只在本機產生 JSON，下載依瀏覽器／WebView 支援，也可選取文字複製。報告不含貼上的原文、請求內容、查詢字串、帳號憑證或原始行車紀錄；本功能沒有自動上傳或發送到 Discord／其他雲端服務。實體手機、車機及道路驗證仍需另外完成。

## 字體大小與 Vision 畫質（0.2.18）

更新車機並重新啟動後，在 **工具 → 網頁設定 → 常規 → 介面字體大小** 選擇 80%、90%、100%、110%、125%、150%、175% 或 200%。網頁與 CarrotAssist 內的網頁內容共用此設定，儲存後立即套用並在重新開啟後保留；影像、地圖和路徑的座標比例不變。

App 原生搜尋頁、標題列與對話框可另外調整：安裝 **0.2.18**，點上方裝置名稱 → **App 原生介面字體大小**，選擇比例後按 **套用並重新載入 App**。這個比例以手機原有系統字體大小為基準，保存在手機，不會與網頁字體比例重複相乘。重新載入後可能需要重新選擇裝置。

在 **工具 → 網頁設定 → Carrot Vision** 可分別調整：

| 選項 | 用途與套用方式 |
|---|---|
| Vision 串流解析度 | 標準保留原有畫質，另提供 360p、540p、720p。實際道路影像由專用硬體編碼器縮放，低解析度使用較低碼率以減少流量與解碼負擔。保持來源比例，不放大超過來源；寬度依來源比例與硬體對齊要求決定 |
| Vision 繪製清晰度 | 自動保留原有顯示策略；省電、標準、高畫質分別調整道路疊圖與 HUD 的繪製像素密度。儲存後立即套用，不會改變攝影機串流的解析度 |

串流解析度由所有觀看者共用。變更後請先結束所有 Vision 觀看，等待約 2 秒，再重新連線；仍有其他觀看者連線時保留既有解析度。可在 Live View 詳細資訊確認實際收到的影像尺寸。停車觀看與全螢幕、Fit／正常／裁切設定仍可使用。這些選項不改變駕駛模型、行車錄影或車輛控制。

## Carrot Vision：App 全螢幕與當前事件（0.2.17）

[下載已簽章的 0.2.17 APK](https://github.com/TonyBinheWu/sunnypilot/releases/download/carrot-assist-tw-v0.2.17/CarrotAssist-TW-0.2.17.apk)。App 與車機須一併更新。開啟即時 Carrot Vision 後，App 會自動使用 Live View 全螢幕，隱藏原生「CarrotPilot／裝置 IP」列、浮動語音鈕與 Android 系統列。按畫面右上方 **退出全螢幕** 或 Android 返回鍵可恢復原介面；退出後不會立刻自動重入。離開 Vision、重新搜尋或換頁時恢復標題列，回放與迷你 HUD 不自動進入此模式。可由「視覺全屏」控制自動進入，關閉時仍可用全螢幕按鈕手動進入。

App 全螢幕預設使用「完整影像／Fit」，依原比例呈現，不為填滿螢幕而裁切；不同長寬比會有留黑。模式內可切換視野，僅影響當次全螢幕，退出後恢復既有網頁偏好。這是依 CommaView 使用情境調整 Carrot 自身介面，並非執行或鏡像該 App。

**當前事件** 在寬螢幕側邊逐項列出目前警示、整體／橫向／縱向控制啟用、方向燈、盲區與制動保持等目前有提供的狀態。踏板、駕駛轉向、駐車制動僅在資料來源包含對應欄位時顯示，不從其他訊號推測。每個來源獨立檢查新鮮度，超過 1.5 秒即移除其事件；停車時不沿用上次行車資料，回放則保留該時間點的紀錄。沒有新資料時顯示「等待新鮮車輛資料」。面板可收合，窄螢幕預設收合；原本重要行車警示仍保留。這是唯讀事件清單，不是歷程時間軸或額外錄影功能。

可安裝 Android APK 的 Android 盒子可使用橫向版面，不鎖定方向；工具按鈕可觸控並收合。只有 CarPlay 接收功能的車機不能直接安裝 APK，盒子廠商或 CarPlay 接收端保留的系統列不一定能由 App 隱藏。本次以本機模擬資料與自動化測試驗證，實體 Android 盒子／手機、CarPlay 大螢幕與實車影像仍待驗收。

## Carrot Vision：Live View 道路影像版面（0.2.16）

更新車機的 `carrot-wip` 並重新啟動，再安裝上方最新版 CarrotAssist（此版面自 0.2.16 提供）。開啟 Carrot Vision 後，點 App 上方的「▣」切換鍵，或在 **工具 → 網頁設定 → Carrot Vision → Vision 顯示版面** 選擇 **Live View 道路影像**。原有儀表仍為預設；此選擇儲存在車機，重新開啟網頁仍保留，切換後立即生效，不必重啟。

版面參考 [CommaView Live View](https://commaview.com/) 的道路影像與底部車速資訊配置，以 Carrot 自身資料呈現，並非 CommaView 原生 UI 鏡像。道路影像、車道／路徑、前車標記沿用既有 Carrot Vision 串流與疊圖；需要車機提供相應模型資料，不會因切換版面自動開啟鏡頭或改變駕駛控制。

- **底部面板：** 顯示車速、巡航設定速度與道路速限，沿用原有 km/h／mph 單位。來源缺少數值顯示「—」，不推測速限。
- **狀態：**「橫向控制啟用」只代表收到橫向啟用資料，不代表縱向巡航也啟用。「監看中」也不代表系統正在控制車輛。
- **全螢幕：** 橫向時可切換，仍須瀏覽器支援；新版 APK 加入 Android WebView 全螢幕容器，返回鍵先退出全螢幕。
- **詳細資訊：** 展開檔位、跟車格數、處理器溫度及影像解析度、畫面更新 fps、RTT、位元率。未知或過期統計顯示「—」；回放不顯示即時串流統計。
- **影像狀態：** 由既有畫面呈現事件判斷「等待影像」「影像正常」「影像暫停更新」「影像重新連線中」。單純收到車速資料或 WebRTC 仍連線不代表有新畫面，延遲到達的 RTP 對應也不算新影格。此處只顯示狀態，重連仍交由原有串流流程處理。
- **車速面板：** 可暫時隱藏／顯示底部車速、定速與速限；不會隱藏原有駕駛警告或關閉車道／路徑。
- **視野：** 循環切換既有符合／一般／裁切模式。使用原來的視野設定與投影流程，選擇會存到車機；儲存失敗顯示繁中錯誤並保留原值。
- **工具列：** 右上「隱藏工具列」收合，「顯示工具列」叫回。App 上方 **▣** 仍可切換版面，**長按 ▣** 也能收合／展開工具列。直向時工具列排成底部按鈕，矮畫面可水平捲動。工具列與車速面板的顯示狀態僅保留在當次網頁工作階段，重新載入會恢復顯示。
- **原有儀表：** 隨時返回原有儀表，或再次按 App「▣」切換。手機直向時，工具列會移到影像底部。

Live View 超過兩秒未收到 HUD 更新時，以繁中顯示「HUD 資料更新逾時」並清除舊車速等值。這是 HUD 更新提示，不能用來判定鏡頭或雲端通道是否健康。錄影回放沿用回放時間，暫停不套用即時資料逾時。設定儲存失敗會還原原值並提示檢查連線。

0.2.16 另以使用者提供的 CommaView 0.0.166-alpha.9 APK 做靜態結構參考，改善 Live View 操作與狀態呈現；未執行該參考 APK，亦未複製其程式或素材。本次驗證使用模擬資料檢查橫直向、繁中標籤、原有儀表切換、資料逾時、工具列及車速面板切換、影格狀態與儲存失敗。尚未進行實體 Android 手機及車機影像驗收；沒有加入 CommaView 專有執行環境、錄影或子母畫面功能。

## 停車時觀看 Carrot Vision

更新車機 `carrot-wip` 並完整重新啟動一次後，在設定搜尋並開啟 **啟用 Carrot Vision**，再從 App 或網頁開啟 Vision。既有 CarrotAssist 0.2.16 可直接使用，不需另外安裝 APK，也不需要執行鏡頭測試或切換強制行車模式。

停車觀看由實際會話按需請求鏡頭及專用串流編碼器；停止觀看、退出或會話被回收後會釋放請求，程序中斷留下的請求也會自動到期。其他功能若仍需要鏡頭（例如駕駛員預覽或 FormosaLink），則由各自原有條件維持，不會被此觀看功能關閉。鏡頭串流仍遵循原有單一觀看所有者及接管規則。

停車影像不啟動駕駛模型、行車控制及一般行車錄影，也不顯示前次行車留下的車速、定速或路徑；若車機沒有新模型資料，就只有鏡頭畫面。錄影回放仍顯示紀錄資料。停車熄屏時保留鏡頭所需核心，原有低電量／關機條件不變，裝置仍須有供電與網路。

本次以自動化測試驗證觀看請求到期、停車程序條件、會話關閉及網頁狀態；尚待 C3X／C4／C4P 實機影像驗收。

## 連線方式

1. 手機與 comma 裝置連至相同 Wi-Fi 或手機熱點。
2. 點裝置畫面的白色胡蘿蔔圖示，掃描其 QR Code，或取得裝置 IP。
3. 瀏覽器開啟 `http://裝置IP:7000`，例如 `http://192.168.0.25:7000`。
4. 「工具 → 語言」選「繁體中文」。此選項只設定 Carrot Web 語言。
5. 裝置本身的語言需另設定：C3X 選「裝置 → 變更語言」，C4 選「設定 → 語言 → 中文（繁體）」，依提示重新啟動。

網頁使用 `zh-tw` 語系；自動辨識繁體標籤及裝置的 `main_zh-CHT`。已儲存的語言優先，舊版若儲存了簡體中文，請手動切換一次。

Carrot Web 適用於手機、平板與電腦瀏覽器；iPhone 可使用網頁。CarrotAssist 是另外提供的 Android App，用於尋找裝置、開啟網頁與語音操作；此倉庫沒有 iOS App。不要將這個區域網路管理服務的 7000 埠直接開放到網際網路。

## Android CarrotAssist

本分支的 Android 原生介面新增繁中，依手機的 `zh-Hant`／臺灣／香港／澳門語系顯示，與網頁語言分開。已提供 [0.2.17 已簽章 APK](https://github.com/TonyBinheWu/sunnypilot/releases/download/carrot-assist-tw-v0.2.17/CarrotAssist-TW-0.2.17.apk)。繁中版使用獨立套件，可與原版並存；新 App 的授權與設定分開保存。

App 可搜尋同網路裝置、手動輸入 IP、開啟 Carrot Web、檢查 App 更新、開啟手機預設助手與使用直接語音。App 更新、車機 Git 更新及中繼服務更新是各自獨立的流程。

### 手機直接語音

依既有指南，CarrotAssist 0.2.11 可使用 Android 12 以上的裝置端語音辨識，需要可用辨識服務、語言模型及麥克風權限。直接語音不需 ChatGPT 帳號、訂閱或配對碼；須讓已驗證的 Carrot Web 保持可見。

可操作項目：

- 搜尋設定，例如 `Find acceleration settings`。
- 開啟方向燈設定，例如 `Open turn signal settings`。
- 指定設定的整數值，或操作同次搜尋的編號結果；僅限允許語音修改且符合範圍的設定。
- 明確要求向左或向右變換一個車道；須另有駕駛權限，並符合既有車輛條件。
- 呼叫預設助手，例如說出 `ChatGPT`。

**0.2.13 新增繁體中文直接語音。** 手機使用繁體中文語系時會要求 `zh-TW` 辨識；仍需手機提供可用的裝置端國語語音模型。App 與車機 `carrot-wip` 必須一起更新，並在停車時完整重新啟動車機。

| 目的 | 可說的指令 |
|---|---|
| 搜尋 | 「搜尋加速度設定」、「搜尋螢幕亮度」 |
| 修改設定 | 「把螢幕亮度設為八十」、「把加速度設定零改成二百四十」 |
| 搜尋結果 | 「把第一個設為二百四十」；目標必須仍是目前畫面上的搜尋結果 |
| 變換一個車道 | 「向左變換車道」、「請往右換一個車道」 |
| 指定巡航速度 | 「巡航速度設為一百公里」、「把定速速度調到100」 |
| 降低巡航速度 | 「巡航速度降低十公里」；「定速減速」使用既有減少 10 km/h 行為 |
| 提高巡航速度 | 「巡航加速」，相當於既有 RES/+ 一次；不是指定加速幅度 |
| 停止聆聽 | 「停止聆聽」 |

數字可使用阿拉伯數字、全形數字、國語數字或逐字讀數；`一百二` 有歧義會拒絕，請說 `一百二十` 或 `一百零二`。設定仍限裝置允許的整數值，不會把模糊名稱猜成某個參數。

若辨識器沒有提供巡航指令的可信度分數，App 會要求覆誦含相同動作與數值的「確認…」句子，例如「確認巡航速度設為100公里」。確認在提示播完後六秒內有效，不能只說「是」，換值、逾時、離開畫面或其他指令會使確認失效。問句、否定句、複合駕駛指令、候選結果衝突及過期結果不會送出駕駛請求。

設定與巡航速度結果會回讀裝置；「已收到請求」與「已套用」分開回覆，巡航目標值不代表實際車速。未在本次進行車內辨識率或實車操控測試。語音服務需求可參考 [Android 語音辨識文件](https://developer.android.com/reference/android/speech/SpeechRecognizer)。

### 中文語音模型與權限引導（0.2.14）

點 App 上方裝置名稱，再選「中文語音檢查與安裝」。不需連車機；模型或麥克風權限錯誤也會自動開啟。

1. 按「授予麥克風權限」，或「開啟 App 權限設定」手動允許。
2. 權限已允許仍不能收音時，檢查快速設定／隱私設定的「麥克風存取」總開關及語音服務權限。
3. Android 13 以上會區分已安裝、可下載、等待下載、不支援及無法確認；只有精確 zh-TW／zh-Hant-TW 模型會被標成已安裝，通用中文資訊不會被當成台灣模型已就緒。
4. 顯示可下載時，按「下載中文語音模型」並處理系統確認。Android 14 以上及服務支援時才有進度回報；送出請求、排程下載或進度 100% 都不會當作安裝完成，完成回報後會重新查詢。
5. Android 12 或不支援查詢／下載的服務，請按「開啟語音輸入設定」，尋找「中文（台灣）／國語／zh-TW」離線語音，選單依手機及服務不同。沒有適用服務時，先由手機官方商店更新辨識服務。
6. 返回 App 會重新檢查。完成後關閉引導，再手動點麥克風；不會自動聆聽或重送原本指令。

沿用相同簽章，可覆蓋更新並保留設定；未實機驗證各廠牌下載流程。參考 [Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)。

### 透過 ChatGPT 連線

此路徑需要已部署的 CarrotAssist 中繼服務、ChatGPT 連線及對應的裝置程式。授權代碼在五分鐘內有效，應貼至授權頁面，勿傳到聊天。

| 分開授予的權限 | 可操作範圍 |
|---|---|
| 基本連線 | 搜尋、解釋與開啟設定畫面 |
| 設定存取 | 讀取目前值、依明確設定及數值修改受支援設定、回讀結果 |
| 駕駛指令 | 請求左／右變換一個車道、增加／降低巡航設定速度、指定目標速度 |
| 工具操作 | 開啟工具面板，依既有確認流程請求 Git 更新、重新啟動、重建、校正重設、備份、錄影、刪除與 tmux 診斷上傳 |

裝置權限不會互相自動擴張；ChatGPT 的工具核准與裝置授權也相互獨立。設定值修改保留原有驗證及生效時機，部分設定不可透過語音修改。

駕駛指令的限制：

- 車道變換仍須通過輔助啟用狀態、速度、車道幾何、盲點、轉向扭矩及駕駛優先權檢查。
- 車速指令只改變已啟用且受支援的 openpilot 縱向控制之設定速度，不會自行啟用輔助；原廠 PCM 控速配置可能拒絕。
- 「設定值已套用」不代表實際車速已達目標；「已接受」、「執行中」與「完成」是不同狀態。
- 過期、重複、衝突或狀態不明的請求可能遭拒，結果不確定時不自動重試。
- 撤銷權限可阻止新指令與待執行準備，不會強制中止已進行的轉向動作。
- 語音不接受任意 shell、網址、路徑、提交或分支目標；檔案、QR Code、剪貼簿與部分倉庫選擇仍需直接操作手機。
- 語音不提供任意方向燈直接控制、行程分析或行車記錄上傳；tmux 診斷上傳是另一項工具功能。

語音辨識、網路及助手處理有延遲，不能當作緊急控制介面。駕駛須持續注意道路並能立即接管。

## 各頁面詳細操作

### 駕駛畫面與畫面配置

進入「駕駛」後，可在可用內容中選擇道路影像、Carrot Vision、HUD 與導航。切換橫向／直向配置、分割區域、全螢幕或交換內容，影響的是目前瀏覽器的顯示方式。畫面沒有資料時，先確認車機正在提供對應影像或狀態；導航疊圖還需要有效的位置、姿態及導航資訊。瀏覽器顯示可能有延遲。

### 設定搜尋、收藏與詳細說明

在「設定」輸入繁體中文名稱、說明關鍵字或參數英文名稱。選取項目後可查看目前值、預設值、可調整範圍、單位及選項，再依控制項修改。數值越界或項目不允許修改時，應以畫面回報為準。長按項目可管理收藏；設定檔可保存一組值，套用前應核對要寫入的項目。

選取詳細說明可閱讀逐項解說。繁體中文版本隨車機網頁提供，212 項設定不需要連到外部 Wiki 才能顯示；預設值、範圍與選項直接由本分支設定目錄產生。既有 Wiki 人工解說保留來源與審查狀態；標示「待審查」代表尚未確認人工解說符合目前參數語意。設定儲存成功不表示已立即生效，仍須遵循該設定的重新啟動、停車或車型條件。

### 導航地圖與目的地

在網路相關設定填入所需的 Mapbox 金鑰後，從「工具 → 導航地圖／Navigation」開啟搜尋頁，輸入目的地並點選搜尋結果。按 **結束當前導航** 可清除本頁設定的目的地，保留我的最愛；外部導航仍須在來源 App 結束。當前目的地只保留於目前行程，行程結束或車機重新啟動後清除。

**我的最愛** 支援新增、自訂名稱、編輯名稱與地址、刪除確認及一鍵導航。按「新增最愛」，填入名稱（例如「家」「公司」）、搜尋地址、點選正確結果後儲存；也可從搜尋結果按「加入最愛」，或按「收藏目前目的地」帶入地址，再於編輯器搜尋並選取儲存位置。修改地址後必須重新搜尋並選取，避免名稱與舊座標混用。僅修改既有名稱可直接儲存。點清單上的名稱即設為目前目的地，不必再搜尋；按「刪除」再按「確認刪除」移除最愛，取消則保留。

最多儲存 100 筆，名稱最多 80 字。最愛保存在車機 `/data/carrot/state/navigation_favorites.json`（資料目錄可由部署環境調整），APK 與網頁共用同一份；重新啟動與一般程式更新後仍保留，不會跨車機或跨裝置自動同步。新增、編輯、刪除最愛不會自動改變正在進行的導航；需點一下最愛名稱才會設定目的地。儲存失敗會保留編輯內容並顯示繁中錯誤。

最愛的地址搜尋使用 [Mapbox 永久地理編碼](https://docs.mapbox.com/help/dive-deeper/understand-temporary-vs-permanent-geocoding/)，需使用者帳號支援，並依 Mapbox 費率計費；一般臨時目的地搜尋維持原模式，最愛一鍵導航與只改名稱不重新搜尋。此功能由車機網頁提供，既有 CarrotAssist 0.2.16 可直接使用；更新車機並重啟後重新開啟導航頁，無需更換 APK。本次已用本機模擬地址驗證介面及儲存流程，尚未實測實體 Android 手機或實車路線。

路線地圖需要啟用行車畫面、有效 GPS 與路線導引。只有儲存金鑰不會產生路線。外部導航優先，外部連線結束後恢復目前行程的 Mapbox 目的地。地圖頁會分別提示等待 GPS、等待路線、偏離路線、地圖載入中或無法取得圖資；請依提示檢查金鑰、網路與位置。

### 行程回放、記錄與錄影

在行程／記錄清單選擇已有資料的行程與區段，載入後操作播放、暫停、播放速度及區段切換。可用的影像、HUD、事件與圖表取決於實際記錄內容。缺少影片或狀態資料時，不代表其他區段也不存在；請查看載入狀態。開始實際行車後，系統可能停止回放。

螢幕錄影功能會切換裝置的錄影狀態。開始後檢查 REC 指示，停止後到錄影清單確認檔案，再播放或下載。行程影片與螢幕錄影是不同資料來源。下載、上傳與刪除各有獨立操作；執行刪除前請確認選取的資料，畫面上的成功或失敗訊息才是操作結果。

### 藍牙遙控器

從「工具 → 藍牙」啟用藍牙、搜尋裝置，讓遙控器進入配對模式後配對。選擇輸入類型，設定每個按鍵的短按、連按兩下與長按對應，儲存後再開始按鍵登錄／測試。測試模式只顯示輸入，不向車輛傳送指令；修改對應後需再次儲存。啟用對應會攔截該裝置原始 HID 輸入。

可選操作包含巡航加／減速、10 單位調整、跟車距離、駕駛模式、LFA、車道線模式、左／右變換車道、撥片減速、CarrotCruise 與取消巡航。實體方向燈功能僅適用支援的 Jetson USB-CAN／B1 車輛。是否能執行仍取決於既有車型支援、輔助狀態、速度、盲點與轉向條件。

連按兩下的放開間隔為 350 毫秒；指定該功能後，短按會等待相同時間。長按於持續按住 700 毫秒後執行；巡航加／減速隨後每 500 毫秒重複。放開、斷線或既有駕駛介入條件會停止重複。最多可保存 16 台裝置；測試只作用於選取裝置，其他已啟用裝置仍可能運作。頁面內亦提供完整時序、配對、測試與多裝置說明。

### 工具、備份與維護

#### 重新執行設定引導

網頁與 CarrotAssist APK 可從「工具 → 重新執行設定引導」，回到初次安裝的語言、車型、HDA 代次與駕駛控制方式畫面。更新車機並重新載入網頁即可；既有 CarrotAssist 0.2.18 不必重裝 APK。

1. 停車排 P 檔並關閉轉向／巡航控制，或停車熄火後操作。車機必須能提供有效的即時狀態；行駛中或狀態無法確認時不能開啟或套用。
2. 重新選擇網頁語言、車型、HDA 與線束／控制方式。車型、HDA 與控制方式皆可選「保留目前設定」，保留自行調校的組合。非 Hyundai／Kia／Genesis 車型不顯示 HDA 步驟，也不更改 `CanfdHDA2`。
3. 選項會先暫存在這次引導中，尚未寫入車機；最後確認頁列出原值與新值。按「確認並套用」才儲存，按「取消設定」則返回工具、保留原值。其他人同時修改相關設定時，須取消後重新開啟引導再確認。
4. 若變更車輛配置，依完成頁提示保持停車，完整重新啟動車機後再使用駕駛輔助；引導不會自動重啟。只有網頁語言變更時不必重啟。

選擇「ADAS・雷達縱向」「攝影機縱向」或「原廠」會使用既有預設組合，可能覆蓋 `HyundaiCameraSCC`、`SpeedFromPCM`、`DriverMonitoringMode`、`EnableRadarTracks`、`EnableCornerRadar`、`AutoCruiseControl` 與 `AutoEngage` 的自訂值。只想更正 HDA 或車型時，控制方式請選「保留目前駕駛控制設定」；套用前以差異清單為準。請依實際車輛與線束選擇，介面選項不會改變實體接線。

重新引導不會清除校正、配對、其他參數或既有完成紀錄。若要匯入備份，請先取消引導，再使用工具的「還原設定」，避免匯入檔立即覆蓋正在暫存的選擇。寫入失敗會嘗試還原此次已寫入的值；若顯示未完整還原，請保持停車，核對設定後再使用。若因連線中斷而無法確認是否已儲存，請取消並重開引導，讀取實際值後再操作。

「工具」提供車型、語言、網頁偏好、裝置資訊、Git 與系統維護等入口。切換網頁語言與切換車機語言分別生效；車機語言請選「中文（繁體）」並依提示重新啟動。Git 操作會影響車機程式版本，請先確認目前倉庫、分支及畫面提示，再執行對應動作。

備份用於匯出設定，還原時須選取正確檔案並確認結果。重新啟動、重建、校正重設、記錄刪除等工具會依原有確認與車輛狀態限制執行。重建期間須等待建置完成；繁中化與滑動最佳化本身不變更車輛控制參數。

### 終端與遠端協助

終端頁可查看並操作既有終端工作階段。遠端分享由擁有者建立工作階段，對方使用分享網址與 PIN 連線。可分別設定僅查看、逐條核准或完整控制；逐條核准的指令有有效期限，拒絕或逾期不會執行。擁有者未查看終端時，頁面會顯示對應狀態。遠端客戶端可依瀏覽器或儲存語言顯示繁體中文。

### 車機滑動與故障復原

C3X 與 C4 共用文字排版快取：捲動只改變位置時沿用排版，內容、寬度或字型改變時重新計算；換行快取最多保留 1024 筆。此修改減少重複文字量測與表情符號解析，沒有變更駕駛控制迴圈。已完成桌面測試，尚未量測 C3X／C4 的實機幀率。

更新後請在安全停車時比較功能設定、網路清單、長說明與返回手勢。若仍卡頓，記錄頁面、裝置型號、是否行車中、是否開啟影像／回放／除錯資訊及時間，才能進一步區分繪圖、觸控或系統負載。啟動失敗的復原畫面也會依裝置繁中語言設定顯示繁體中文，原始錯誤與診斷內容仍保留。

## FormosaLink 雲端連線

## 轉向延遲與扭力學習進度

- **網頁／CarrotAssist APK：** 開啟 Carrot 網頁，進入「工具 → 轉向學習進度」。既有 0.2.18 APK 可直接使用更新後車機提供的網頁，不必另外安裝新版 APK。
- **車機：**「設定 → 設備（裝置）→ 轉向學習進度」；C4 為「轉向／學習」按鈕，採小螢幕全頁捲動，回到頁首後向下滑即可返回。
- **轉向延遲：** 顯示資料進度、驗證狀態、選定延遲、候選估計延遲（秒）與有效資料區塊。
- **轉向扭力：** 顯示資料進度、驗證狀態、選定側向加速度係數、摩擦補償與樣本數。不適用即時扭力學習的控制方式會另外標示。

「資料進度」代表學習資料的涵蓋程度，不是已開多久；總樣本數增加，進度仍可能不變。100% 也不保證估計通過驗證，請一起看狀態。無資料顯示「—」，不會假設是 0%。請正常駕駛，不要為了增加進度刻意左右轉向。

畫面會區分「即時資料」「資料已過期（上次收到）」與「上次保存紀錄（非即時）」。停車後學習程序可能停止，此時顯示歷史數值不代表正在學習；不同車型或不相容調校的保存紀錄不會混用。開啟自訂調校時會標示自訂值優先，不宣稱學習值已套用。

此畫面只供查看，不會重設學習、不會更改轉向設定，也不會讓學習自動生效。更新車機後重新開啟網頁／APK 即可使用；請停車時查看。


## 俯視視覺、速度資訊配置與彩虹路徑

車機更新後，網頁與既有 CarrotAssist 0.2.18 APK 皆可使用，重新載入網頁即可。進入「工具 → 網頁設定 → Carrot Vision」，將「Vision 顯示版面」選為「特斯拉風格俯視視覺」。保留原有 Carrot 儀表及 Live View 道路影像版面，隨時可切回。進入俯視模式時先收合工具列與事件面板，可按「顯示工具列」再展開。

俯視圖使用既有模型的路徑、車道與道路邊界，以及雷達回報的前車位置，並繪製本車示意；不是 Tesla 原生畫面，也不是環景攝影或完整 360 度障礙物偵測。俯視圖也沿用既有 Vision 繪製清晰度選項，低畫質降低繪製負擔，高畫質提高繪製解析度。沒有回報的車輛不會憑空補畫。模型或雷達資料超過 1.5 秒未更新會分別移除，停車即時模式不沿用之前行車的偵測；回放則依回放資料顯示。

開啟「自訂速度資訊位置與大小」，在 Carrot View 按「調整資訊（停車）」即可分別拖曳「當前時速」「道路限速」「巡航設定速度」；選取資訊卡片後用大小滑桿調整為 0.6–2.2 倍，按「儲存配置」保留。也可用 Tab 聚焦卡片、方向鍵移動，或按「還原配置」後儲存。位置以可用畫面的比例保存，橫直向及全螢幕切換時仍限制在畫面內；不要把資訊放在警告或操作按鈕上。即時編輯限已確認停車或非行車狀態，回放可編輯；車況改為行駛時中止未儲存的調整。改變配置不會修改巡航速度。俯視模式自動使用這三張資訊卡片。

「特斯拉風格彩虹路徑」會將行駛路徑顯示為七色，支援道路疊圖及俯視模式；車道線、警告、實際模型與車輛控制沿用原有流程。未知或過期速度仍顯示「—」，不推算速限。

## 錄影循環空間配額

「工具 → 網頁設定 → Carrot Vision → 錄影空間上限」可選擇關閉或總容量的 10–90%，預設關閉。車機原生 routes 與車機產生的日期命名畫面錄影，合併計算在各自檔案系統的總容量中；若兩類檔案位於同一磁碟，便共用一份配額，不會各占一份。下載到手機或電腦的錄影不在管理範圍。

例如：總容量 100 GB、設定 50%，當符合管理範圍的錄影達到約 50 GB 時，程序會每約 30 秒檢查並分批清理最舊的完整行程或畫面錄影，目標約 48 GB。完整行程一併處理，避免留下缺少前後片段的回放；一次最多清理四筆，可能需要多次檢查才能回到上限內。

此配額清理排除使用中、近兩分鐘仍有寫入、帶鎖定或保留標記的紀錄；同一行程只要有一段受保護，就保留整個行程。也不處理 boot、crash、外部連結、非日期命名影片、其他資料夾及設定備份。畫面錄影管理範圍為 `/data/media/0/` 下的 `videos`、`screenrecord`、`screen_recordings`、`screenrecords`、`ScreenRecords`；匯入檔若放在這些資料夾且使用日期命名，也可能被計入與清理，重要影片請另存到管理範圍以外。沒有可刪紀錄或掃描權限不足時停止此輪，不會為了符合配額強刪；可在「工具 → 錄影儲存空間狀態」查看占用、過期或超額狀態，約 30 秒後重新開啟可更新。

自動刪除無法從應用程式還原，重要檔案請先下載保存。原有車機空間不足保護維持作用，可能在尚未達到此配額之前就清理 routes，並不受此選項關閉影響。本功能需要更新並重新啟動車機，讓清理程序載入新版本。


## BEV（鳥瞰）標註與匯出

車機更新後，在「工具 → 網頁設定 → Carrot Vision → Vision 顯示版面」選擇「BEV（鳥瞰）標註」。這是在現有模型與原生前車資料上加上分析標註的工作台，支援網頁與既有 CarrotAssist 0.2.18 APK；原有三種版面、速度資訊配置及彩虹路徑皆保留。

### 能查看的資料

- **等比例公尺格線：** 前方視距可選 30／50／75 公尺，縱橫使用相同的公尺比例，並提供 5 公尺比例尺。車身圖示為示意尺寸，不能據此量測車長或車寬。未標記區域不代表已確認可通行，也不是占用網格。
- **模型輔助標註：** 路徑、車道線、道路邊界，以及來源提供的前車目標。`p` 是模型回報的車道機率，並非已校準的道路安全分數；`σ` 是模型的不確定度欄位，不是實測定位誤差。低機率或機率不明的車道以虛線輔助標示，未知值不補成零。
- **前車資訊：** 前方距離、相對速度 `Δv`（m/s）、來源是否使用雷達，以及可用的原生軌跡編號。`leadOne`／`leadTwo` 是前車角色槽位，原生軌跡編號也可能被回收，不能當作跨行程永久物件身分。
- **座標與時效：** 模型座標採 x 向前、y 向右；前車原生 yRel 向左，因此顯示及匯出時反號。各來源仍保留原本縱向參考原點，未宣稱完成精確感測器外參對齊。接收時間只用於顯示時效，不代表硬體感測同步；即時資料過期或停車後不延用舊的模型／前車資料。一般俯視版面的模型左右顯示方向也一併修正，不改變實際轉向控制。

### 人工補註

1. 在停車或回放狀態展開「BEV 標註工具」，按「凍結標註快照」。模型、前車與速度卡片會保持該快照，畫面明確顯示「非即時」。沒有有效來源資料時不能建立快照。
2. 選擇未知、車輛、行人或標誌等人工類別，收合工具，再點擊圖面新增點標記。這些類別均標為「人工／待驗證」，不是模型新增的辨識結果。
3. 「車道修正（人工）」需依序點選至少兩點，再展開工具按「完成修正線條」。每條線最多 64 點、每張快照最多 64 筆人工標記；「撤銷人工標記」先撤銷尚未完成的線條點，再撤銷最後一筆人工標記。
4. 按「恢復即時／回放」會恢復目前來源，上次快照仍可查看或匯出；改成行駛狀態會自動停止凍結與人工編輯，但保留分頁內的既有快照草稿。建立新的快照前，若舊草稿已有人工標記，會先詢問是否取代。

草稿僅存在目前分頁的記憶體，重整、關閉或 App 終止後不會保留，請先匯出。只修改標註資料，不會更動模型、車輛設定、路徑規劃或控制命令。

### 匯出格式與限制

「下載 JSON（瀏覽器）」輸出 `carrot-bev-annotations/v1`，包含座標規則、瀏覽器端快照時間、可用模型影格編號、來源接收時間、原生參考原點、模型輔助向量、人工標記及速度顯示值。模型輔助資料標為 `model_assisted`，人工資料標為 `human_unverified`；整份資料的 `groundTruth`、`reviewed` 與 `frameSynchronized` 都不會被自動宣告為真。

「下載 PNG（瀏覽器）」輸出同一張凍結 BEV 圖，含格線、來源估計與人工標記，不包含攝影機影像。APK 若不支援瀏覽器檔案下載，可按「檢視／複製標註 JSON」，或用外部瀏覽器開啟車機網頁再下載。匯出皆由使用者操作，不自動上傳雲端，也不自動餵回駕駛模型。

本工作台參考[文章中的資料標註概念](https://electrify.tw/tesla-ai-powered-labeling-patent/)及[導航資料標註專利說明](https://patents.google.com/patent/WO2024073033A1/en)，提供現有資料可支援的檢視與補註功能。下方另有觀看端前方影像辨識，可補充可見物件的類別與地面估算位置；沒有加入新訓練的駕駛模型、多攝影機神經網路融合、號誌 BEV 偵測、車道連接推論、占用網路或車隊高精度 3D 地圖。這些 JSON／PNG 不是已驗證的真值，也不含配對攝影機訓練影像；若要作為訓練資料，仍需另外處理感測同步、校正、原始影像配對、人工審核與離線訓練評估。

### 行駛中的即時鳥瞰與特斯拉風格畫面

請先更新 `carrot-wip` 並完整重新啟動車機，再重新開啟網頁或 APK，載入新的設定與畫面。之後只切換顯示偏好或彩虹道路開關，不必再次重新啟動。

BEV 與特斯拉風格版面都能在行駛中即時顯示。只有凍結、人工標註、匯出與資訊位置編輯限停車或回放。特斯拉風格版面採淺色道路、藍色預測路徑與立體示意車輛；BEV 保留等比例公尺格線及標註工具。這是本專案的向量繪圖，沒有特斯拉的原廠素材或完整環境感知系統。

兩種版面皆會顯示來源實際提供的前車及左右車道目標。原生目標沒有可靠車種分類，畫面以中性的圈形標記呈現，不會猜成汽車、機車或行人。同一原生目標在不同集合重複出現時，僅在資料足夠相符時合併顯示。看不到的側後方不補出車輛，原生來源過期也不沿用舊位置。

在「工具 → 網頁設定 → Carrot Vision」開啟「前方影像物件辨識（實驗性）」，即可由觀看端的網頁／CarrotAssist 0.2.18 辨識前方影像中的**汽車、機車、行人、自行車、公車與卡車**。對應圖示只在當前影像辨識出該類別、校正資料有效且可估算地面位置時顯示；不支援的類別或無法定位的目標不會硬放進鳥瞰圖。

- **運算位置：** 在觀看網頁的電腦、手機或 Android 盒子的背景工作程序，以 CPU 執行內附的 Google EfficientDet-Lite0 int8 模型。預設關閉，最多每秒 4 次，效能較慢時自動降頻；一次只處理一張影格，沒有排隊累積。模型、WASM 檔從車機提供，首次載入有額外傳輸量；不需要在使用時連到第三方 CDN，不上傳攝影機影像。
- **支援條件：** 新版 Chrome／Edge 或 Android System WebView，支援 Worker、WebAssembly、OffscreenCanvas 與影像縮放。APK 使用車機更新後的網頁內容，這次不需另裝新版 APK。無法載入或不支援時會顯示繁中原因；先更新車機及 WebView，再關閉重開此開關可重試。
- **定位條件：** 道路相機的完整影像比例、已完成的相機校正、相機高度及新鮮的來源資料。缺少資料時可辨識出影像類別，但不繪出地面位置，並顯示需要校正／高度資料。此處只支援目前 Carrot Vision 的道路鏡頭，不把車內或廣角影像當成道路鏡頭定位。
- **位置意義：** 以物件框底端中心與平坦地面相交估算，可能受坡度、遮擋、截斷、模型誤判與網路延遲影響。`≈` 表示估算；圖示尺寸與朝向是示意，不是實測。這不是深度模型、360° 環景或精準的雷達／影像融合，也沒有跨影格身份追蹤。
- **即時性：** 影像辨識超過 1.2 秒未更新就清除舊目標。離開 Vision、切換來源、隱藏頁面或凍結標註會清除／暫停該辨識工作；錯誤或逾時會停止並顯示狀態。回放仍是歷史影像。攝影機與原生雷達來源獨立顯示，同一物體可能在兩個來源都出現；沒有宣稱已對齊感測時刻。

BEV 快照 JSON 會保留影像分類、模型分數、`flat_ground_projection` 位置來源與辨識影格時間，仍標示未審核、非真值且未完成跨感測同步。這套顯示不會把辨識結果送進轉向、煞車、巡航或行車警告；不代表增加了自動閃避或行人煞停能力。

### 機器端彩虹道路（SP 風格）

在機器「開關」選單開啟「彩虹道路（SP 風格）」，或在網頁／APK 設定搜尋 `RainbowMode`。支援 C3／C3X 與 C4 的原生行車畫面；預設關閉，開啟後在橫向控制啟用時，沿用原本預測路徑的幾何形狀，將填色改成 SP 風格的動態彩虹漸層。

不必重新啟動，設定會在介面讀取更新後套用。關閉或橫向控制未啟用時回到原有路徑樣式，既有路徑模式、顏色、其他資訊和警示均保留。此設定與網頁／APK 的「彩虹車道」顯示偏好各自獨立，只改變畫面，不改變模型、轉向扭力或任何駕駛控制。
