# Following distance and restart

[한국어](../ko/cruise-gap.md)

The driving personality sets the lead-vehicle MPC's time gap. Select the personality in the device toggles or with the distance button where supported. Lead distance also depends on vehicle speed and relative motion. At a stop, departure requires the planner to release its stop request and the vehicle interlocks to clear.
