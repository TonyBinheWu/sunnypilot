# Hyundai／Kia 四車系第一階段轉向與彎道輔助

`HkgPhase1Assist` 是預設關閉的選用功能，位於「駕駛控制 → 轉向 → 轉向手感」。只套用程式中明列的 EV6、Ioniq 5、Carnival、Sorento 平台；不改車型辨識、HDA、線組、扭力／角度控制方式或模型檔。

## 已實作行為

- **低速入彎：** 在模型直接提供曲率目標的路徑上，同方向且增大的入彎需求，將原本 0.1 秒目標濾波時間常數最多縮短 40%。≤30 km/h 使用完整調整，30–40 km/h 漸退，≥40 km/h 回到原值。回正、反向、靜止、駕駛介入或資料失效使用原路徑。自訂車道線規劃濾波及其延遲補償不變。
- **低速扭力需求：** CAN-FD 扭力車型沿用既有 `LowSpeedSteerReserve`，持續需求資格為 0.30 秒，≤30 km/h 按需最高 409，主機指令速率最高 4／4 CAN 單位／10 ms，30–40 km/h 漸退。這些不是 Nm、方向盤角速度或已驗證 EPS 能力。角度控制與傳統 CAN Sorento 不取得額外扭力權限。
- **高速平順：** 40–80 km/h 逐漸加入小幅曲率修正濾波，時間常數最多 0.08 秒；大幅需求減少濾波。沒有死區或固定保留的方向盤目標，既有最終曲率、橫向加速度、jerk、扭力／角度與 Panda 限制仍生效。
- **彎前減速：** 僅限直接縱向控制的 ACC 模式，橫向／縱向皆啟用、未踩踏板、未人工轉向且車輛／模型資料有效時工作。使用模型前方最多 4 秒的空間距離與曲率，經連續三個新模型幀確認後提供 MPC 速度上限；重複、跳號或重啟的模型不能累計確認。最低目標為 5 m/s，此新增功能不要求停車。

彎道速度包絡採用以下舒適策略，尚未依實車標定：

`允許接近速度² = max(5², 2.0 / |曲率|) + 2 × 1.2 × 剩餘距離`

距離扣除 0.5 秒當前車速的預留量。包絡上限每秒最多降低 1.2 m/s、每秒回升 0.5 m/s；這是速度目標變化，實際減速度及 jerk 仍由 MPC 和既有控制器決定，不能保證在所有彎道入口前達到目標。孤立單點曲率尖峰經三點中位數處理；非有限值、長度不符、過低預測速度、異常幾何跳變會取消本功能的速度上限。

MPC 會在 Carrot 重新選速後才套用此上限，避免被覆寫；只可降低巡航目標，不提高原有低速／停車目標，也不改前車或交通停車障礙。作用期間禁止滑行與前車加速預覽抵銷彎道減速。原廠 ACC、blended 模式及其他車系不使用新增彎道速度上限。

## 開關與保護

轉向約每 0.5 秒讀取設定，縱向在既有設定輪詢週期讀取。四車系的 CAN-FD 扭力車型，`HkgPhase1Assist` 與 `LowSpeedSteerReserve` 任一開啟均可啟用既有低速需求跟隨；兩者都關閉後才恢復儲存的手動限制。儲存的最大扭力／速率、增益與學習值不被覆寫。

本次沒有修改 EPS 協定、Panda 安全程式、讓步規則或請求位元防故障。仍需前次低速轉向修復所要求的相容 Panda 韌體。駕駛接管、CAN／轉向故障及既有解除控制優先。沒有新增緊急避讓、滿舵指令或迴轉規劃。

`hkg_phase1_curve` 診斷事件每秒最多一次，包含速度上限、目前速度及確認／釋放／無效等原因；不包含位置。低速扭力反應沿用「轉向學習進度」唯讀紀錄，觀察峰值不會提高任何控制上限。

## 驗證與限制

針對性回歸涵蓋所有登錄平台、非目標平台不啟用、實際 cereal 模型陣列、PID／CAN 低速路徑、駕駛讓步、速度退出、左右彎、曲率尖峰、資料過期／重複／重啟、直接控制／原廠 ACC／blended、低速及停車目標優先，另執行原生 C Panda 轉向保護專項。

測試使用主機上的實際控制程式與原生 CAN／Panda 程式；IPC、Params 及外部程序使用隔離測試替身。MPC 邊界測試驗證選速與輸入準備，不代表執行完整原生求解器或實車閉環。合成高速小幅修正測試驗證濾波與無偏差，不等於車輛減少擺動的證據。

沒有刷寫或啟用任何實車。四車系各年式／配置仍需獨立的 rlog、封閉場地與實車驗證；目前不能宣稱滿舵、急彎或 FSD 等效能力。既有完整 CAN-FD 安全套件的不相容項目未由本次工作消除，專項通過不代表完整安全套件或車輛認證通過。

本次驗證結果：控制／規劃／讓步／滑行回歸 417 項、原生 C Panda 轉向專項 47 項、網頁設定 299 項、Wiki 生成與翻譯 34 項通過。文件結構驗證涵蓋四語系 217 個設定；測試環境仍有兩個既有 pytest C++ 設定警告。
