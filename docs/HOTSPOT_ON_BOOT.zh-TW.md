# SIM 行動網路自動分享

在設定搜尋 `HotspotOnBoot`（開啟熱點），啟用後，車機會等待 SIM 就緒且行動數據已連線，再自動開啟既有熱點。手機、平板或車用盒子連上該熱點後，可使用車機的行動網路。沿用裝置網路選單設定的熱點名稱與密碼。

更新程式並重新啟動一次後，開關變更約在五秒內套用，不必每次重新啟動。SIM 較晚連線會持續等待；啟動失敗會間隔重試。未插 SIM、沒有有效數據連線或正在使用專用直連 AP 時，不會搶先啟動。

在裝置的網路選單手動關閉熱點後，本次自動啟動會暫停；將 `HotspotOnBoot` 關閉再開啟，或重新啟動車機，可恢復。關閉這個選項會關閉它自動管理的熱點。行動網路短暫中斷時保留區域網路，手機仍可開啟車機頁面；恢復後由原有網路服務恢復上網。

裝置通常只有一個 Wi-Fi 無線介面，開啟熱點可能取代原本的 Wi-Fi 連線。行動門號必須允許網路共享，並有正確 APN、訊號及可用流量；這個功能不會更改門號方案、APN 或漫遊設定。

程式透過 NetworkManager 的 `ipv4.method=shared` 提供 DHCP、DNS 與 NAT，保留行動網路作為上游路由，並在自動分享時維持必要的 IPv4 轉送。行動網路狀態需為十五秒內的新鮮資料；不會只因為「插有 SIM」就判定可以上網。

可在停車時，從另一台裝置連上熱點，確認同時能開啟 Carrot 頁面及外部網站。若僅能開啟 Carrot，請先確認車機本身的 SIM 數據、APN、剩餘流量及電信業者的共享限制。
