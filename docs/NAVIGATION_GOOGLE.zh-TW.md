# Google 導航方案已停用

2026-11-17 已依使用者要求改用 **Mapbox／OpenStreetMap·Protomaps**。目前的網頁、CarrotAssist與Carrot Cockpit不載入Google Maps／Places，亦不提供Google金鑰入口。

請改讀[Mapbox與OpenStreetMap導航指南](NAVIGATION_MAPBOX_OSM.zh-TW.md)，包含來源分工、Mapbox金鑰、舊最愛重新選址及驗證範圍。舊Google最愛的使用者命名會保留；需明確重新搜尋並選定地址。

此檔案保留供舊連結導向；歷史Google設定方式可從Git歷史查閱。軟體更新不會刪除Google Cloud專案、帳單帳戶或雲端金鑰。
