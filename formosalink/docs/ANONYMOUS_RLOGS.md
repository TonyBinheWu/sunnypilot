# ccNC 匿名錯誤回報

在車機停車時開啟「設定 → 裝置 → 匿名錯誤回報」，閱讀說明，再按「啟用回報」。預設關閉，無須配對或登入。C3X 和 C4 使用相同入口。在同一頁按「關閉回報」會停止傳送並清除本機待傳資料；已收到的回報按伺服器保存期限清除。

## 車主會送出什麼

車機檢查啟用前 24 小時以來、由 `ccnc-port` 寫完的 `rlog.zst`。偵測到指定故障才重建一個可由 openpilot LogReader 讀取的 rlog。每份涵蓋一個分段，以分段開始為第零秒，最多每秒每類一筆狀態。一般開門、未繫安全帶等提示不會啟動回報。停止記錄、斷電時沒有正常結束的分段，或只出現在螢幕而未寫入 rlog 的訊息，都可能沒有對應回報。

- 保留軟體版本、已知車型平台、巡航可用／啟用狀態、ACC/CAN/轉向故障與原廠 AEB/FCW 作動旗標、Panda 故障、部分程序退出碼，以及有寫入記錄的 Chestnut 警告名稱。AEB 作動旗標只能說明當時是否作動，無法證明緊急煞車功能正常。
- 位置、絕對行車時間、原始 CAN、影音、自由文字、憑證、VIN、裝置序號、Dongle ID、行程檔名都不會進入回報。網路連線會向 IIS／反向代理顯示來源 IP；網路存取日誌由站台管理者依設定保留。回報資料庫不存 IP。
- 停車後可先整理資料，等車機連上非計量 Wi-Fi 或乙太網路再上傳。同一行程相同的故障組合回報一次。裝置最多暫存 32 份、保留來源最近七天的待傳資料，斷線或伺服器暫時無法收件時會重試。
- 上傳成功後，這個頁面會顯示最近一份的 12 字元回報碼。車主可自行將代碼提供給維護者。每份回報會產生新的隨機代碼。

## 維護者收件

以 FormosaLink 管理者登入，在首頁開啟「匿名錯誤回報」。可搜尋回報碼、故障名稱（例如 `accFaulted`）、車型平台或版本，並下載 `rlog.zst`。時間欄顯示伺服器收件時間。管理入口為 `/api/v1/admin/anonymous-rlogs`。一般配對帳號沒有讀取權限。

裝置透過 HTTPS 將已去識別的二進位檔送至 `POST /api/v1/diagnostics/rlog`，每次使用獨立的隨機回報碼，不帶 Cookie 或裝置簽章。伺服器依同一份 cereal 結構驗證欄位、事件與大小後，才將重建的壓縮檔存入私有資料目錄的 `anonymous-rlogs.sqlite3`。每份上限 64 KiB，全站上限 4,096 份，保留 30 天。服務執行時每小時清理，過期資料立即停止提供下載。

## 部署

依現有 IIS 或 Docker 部署流程更新後端，建置前先執行 `git submodule update --init opendbc_repo` 取得該版本的車型清單與 schema。IIS 需在主機本機執行已發布的 `App_Data/setup-server.ps1`，安裝 Python 相依套件並重啟私有後端。既有的整合站須合併本功能到其現行後端，保留該站其他服務。完成後 `/api/v1/health` 的 `features` 會包含 `anonymous-rlog-v1`。可用 `python -m pytest formosalink/tests/test_diagnostic_rlogs.py` 驗證收件、去識別、重送與管理權限。
