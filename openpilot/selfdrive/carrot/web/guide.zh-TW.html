返回 Carrot Web 工具各頁面詳細操作

carrotpilot 手機操作指南與功能解析

依本倉庫 carrot-wip 的程式碼及既有指南整理。清單代表程式提供的功能；實際可用性仍取決於車型、裝置版本、資料來源、瀏覽器與權限。本次未進行實車或實體手機驗證。

連線方式

  1. 手機與 comma 裝置連至相同 Wi-Fi 或手機熱點。
  2. 點裝置畫面的白色胡蘿蔔圖示，掃描其 QR Code，或取得裝置 IP。
  3. 瀏覽器開啟 http://裝置IP:7000，例如 http://192.168.0.25:7000。
  4. 「工具 → 語言」選「繁體中文」。此選項只設定 Carrot Web 語言。
  5. 裝置本身的語言需另設定：C3X 選「裝置 → 變更語言」，C4 選「設定 → 語言 → 中文（繁體）」，依提示重新啟動。

網頁使用 zh-tw 語系；自動辨識繁體標籤及裝置的 main_zh-CHT。已儲存的語言優先，舊版若儲存了簡體中文，請手動切換一次。

Carrot Web 適用於手機、平板與電腦瀏覽器；iPhone 可使用網頁。CarrotAssist 是另外提供的 Android App，用於尋找裝置、開啟網頁與語音操作；此倉庫沒有 iOS App。不要將這個區域網路管理服務的 7000 埠直接開放到網際網路。

網頁、設定與維護操作請先安全停車。螢幕錄影不能取代車輛控制問題所需的原始行車記錄。

Android CarrotAssist

本分支的 Android 原生介面新增繁中，依手機的 zh-Hant／臺灣／香港／澳門語系顯示，與網頁語言分開。已提供 0.2.14 已簽章 APK。繁中版使用獨立套件，可與原版並存；新 App 的授權與設定分開保存。

App 可搜尋同網路裝置、手動輸入 IP、開啟 Carrot Web、檢查 App 更新、開啟手機預設助手與使用直接語音。App 更新、車機 Git 更新及中繼服務更新是各自獨立的流程。

手機直接語音

依既有指南，CarrotAssist 0.2.11 可使用 Android 12 以上的裝置端語音辨識，需要可用辨識服務、語言模型及麥克風權限。直接語音不需 ChatGPT 帳號、訂閱或配對碼；須讓已驗證的 Carrot Web 保持可見。

可操作項目：

  • 搜尋設定，例如 Find acceleration settings。
  • 開啟方向燈設定，例如 Open turn signal settings。
  • 指定設定的整數值，或操作同次搜尋的編號結果；僅限允許語音修改且符合範圍的設定。
  • 明確要求向左或向右變換一個車道；須另有駕駛權限，並符合既有車輛條件。
  • 呼叫預設助手，例如說出 ChatGPT。

0.2.13 新增繁體中文直接語音。 手機使用繁體中文語系時會要求 zh-TW 辨識；仍需手機提供可用的裝置端國語語音模型。App 與車機 carrot-wip 必須一起更新，並在停車時完整重新啟動車機。

目的 可說的指令
搜尋 「搜尋加速度設定」、「搜尋螢幕亮度」
修改設定 「把螢幕亮度設為八十」、「把加速度設定零改成二百四十」
搜尋結果 「把第一個設為二百四十」；目標必須仍是目前畫面上的搜尋結果
變換一個車道 「向左變換車道」、「請往右換一個車道」
指定巡航速度 「巡航速度設為一百公里」、「把定速速度調到100」
降低巡航速度 「巡航速度降低十公里」；「定速減速」使用既有減少 10 km/h 行為
提高巡航速度 「巡航加速」，相當於既有 RES/+ 一次；不是指定加速幅度
停止聆聽 「停止聆聽」

數字可使用阿拉伯數字、全形數字、國語數字或逐字讀數；一百二 有歧義會拒絕，請說 一百二十 或 一百零二。設定仍限裝置允許的整數值，不會把模糊名稱猜成某個參數。

若辨識器沒有提供巡航指令的可信度分數，App 會要求覆誦含相同動作與數值的「確認…」句子，例如「確認巡航速度設為100公里」。確認在提示播完後六秒內有效，不能只說「是」，換值、逾時、離開畫面或其他指令會使確認失效。問句、否定句、複合駕駛指令、候選結果衝突及過期結果不會送出駕駛請求。

設定與巡航速度結果會回讀裝置；「已收到請求」與「已套用」分開回覆，巡航目標值不代表實際車速。未在本次進行車內辨識率或實車操控測試。語音服務需求可參考 Android 語音辨識文件。

中文語音模型與權限引導（0.2.14）

點 App 上方裝置名稱，再選「中文語音檢查與安裝」。不需連車機；模型或麥克風權限錯誤也會自動開啟。

  1. 按「授予麥克風權限」，或「開啟 App 權限設定」手動允許。
  2. 權限已允許仍不能收音時，檢查快速設定／隱私設定的「麥克風存取」總開關及語音服務權限。
  3. Android 13 以上會區分已安裝、可下載、等待下載、不支援及無法確認；只有精確 zh-TW／zh-Hant-TW 模型會被標成已安裝，通用中文資訊不會被當成台灣模型已就緒。
  4. 顯示可下載時，按「下載中文語音模型」並處理系統確認。Android 14 以上及服務支援時才有進度回報；送出請求、排程下載或進度 100% 都不會當作安裝完成，完成回報後會重新查詢。
  5. Android 12 或不支援查詢／下載的服務，請按「開啟語音輸入設定」，尋找「中文（台灣）／國語／zh-TW」離線語音，選單依手機及服務不同。沒有適用服務時，先由手機官方商店更新辨識服務。
  6. 返回 App 會重新檢查。完成後關閉引導，再手動點麥克風；不會自動聆聽或重送原本指令。

沿用相同簽章，可覆蓋更新並保留設定；未實機驗證各廠牌下載流程。參考 Android SpeechRecognizer。

透過 ChatGPT 連線

此路徑需要已部署的 CarrotAssist 中繼服務、ChatGPT 連線及對應的裝置程式。授權代碼在五分鐘內有效，應貼至授權頁面，勿傳到聊天。

分開授予的權限 可操作範圍
基本連線 搜尋、解釋與開啟設定畫面
設定存取 讀取目前值、依明確設定及數值修改受支援設定、回讀結果
駕駛指令 請求左／右變換一個車道、增加／降低巡航設定速度、指定目標速度
工具操作 開啟工具面板，依既有確認流程請求 Git 更新、重新啟動、重建、校正重設、備份、錄影、刪除與 tmux 診斷上傳

裝置權限不會互相自動擴張；ChatGPT 的工具核准與裝置授權也相互獨立。設定值修改保留原有驗證及生效時機，部分設定不可透過語音修改。

駕駛指令的限制：

  • 車道變換仍須通過輔助啟用狀態、速度、車道幾何、盲點、轉向扭矩及駕駛優先權檢查。
  • 車速指令只改變已啟用且受支援的 openpilot 縱向控制之設定速度，不會自行啟用輔助；原廠 PCM 控速配置可能拒絕。
  • 「設定值已套用」不代表實際車速已達目標；「已接受」、「執行中」與「完成」是不同狀態。
  • 過期、重複、衝突或狀態不明的請求可能遭拒，結果不確定時不自動重試。
  • 撤銷權限可阻止新指令與待執行準備，不會強制中止已進行的轉向動作。
  • 語音不接受任意 shell、網址、路徑、提交或分支目標；檔案、QR Code、剪貼簿與部分倉庫選擇仍需直接操作手機。
  • 語音不提供任意方向燈直接控制、行程分析或行車記錄上傳；tmux 診斷上傳是另一項工具功能。

語音辨識、網路及助手處理有延遲，不能當作緊急控制介面。駕駛須持續注意道路並能立即接管。

各頁面詳細操作

駕駛畫面與畫面配置

進入「駕駛」後，可在可用內容中選擇道路影像、Carrot Vision、HUD 與導航。切換橫向／直向配置、分割區域、全螢幕或交換內容，影響的是目前瀏覽器的顯示方式。畫面沒有資料時，先確認車機正在提供對應影像或狀態；導航疊圖還需要有效的位置、姿態及導航資訊。瀏覽器顯示可能有延遲。

設定搜尋、收藏與詳細說明

在「設定」輸入繁體中文名稱、說明關鍵字或參數英文名稱。選取項目後可查看目前值、預設值、可調整範圍、單位及選項，再依控制項修改。數值越界或項目不允許修改時，應以畫面回報為準。長按項目可管理收藏；設定檔可保存一組值，套用前應核對要寫入的項目。

選取詳細說明可閱讀逐項解說。繁體中文版本隨車機網頁提供，212 項設定不需要連到外部 Wiki 才能顯示；預設值、範圍與選項直接由本分支設定目錄產生。既有 Wiki 人工解說保留來源與審查狀態；標示「待審查」代表尚未確認人工解說符合目前參數語意。設定儲存成功不表示已立即生效，仍須遵循該設定的重新啟動、停車或車型條件。

導航地圖與目的地

在網路相關設定填入所需的 Mapbox 金鑰後，從「工具 → 導航地圖」開啟搜尋頁，輸入目的地並點選搜尋結果。頁面會回報目前目的地，亦可清除 Mapbox 目的地。目的地只保留於目前行程，行程結束或車機重新啟動後清除。

路線地圖需要啟用行車畫面、有效 GPS 與路線導引。只有儲存金鑰不會產生路線。外部導航優先，外部連線結束後恢復目前行程的 Mapbox 目的地。地圖頁會分別提示等待 GPS、等待路線、偏離路線、地圖載入中或無法取得圖資；請依提示檢查金鑰、網路與位置。

行程回放、記錄與錄影

在行程／記錄清單選擇已有資料的行程與區段，載入後操作播放、暫停、播放速度及區段切換。可用的影像、HUD、事件與圖表取決於實際記錄內容。缺少影片或狀態資料時，不代表其他區段也不存在；請查看載入狀態。開始實際行車後，系統可能停止回放。

螢幕錄影功能會切換裝置的錄影狀態。開始後檢查 REC 指示，停止後到錄影清單確認檔案，再播放或下載。行程影片與螢幕錄影是不同資料來源。下載、上傳與刪除各有獨立操作；執行刪除前請確認選取的資料，畫面上的成功或失敗訊息才是操作結果。

藍牙遙控器

從「工具 → 藍牙」啟用藍牙、搜尋裝置，讓遙控器進入配對模式後配對。選擇輸入類型，設定每個按鍵的短按、連按兩下與長按對應，儲存後再開始按鍵登錄／測試。測試模式只顯示輸入，不向車輛傳送指令；修改對應後需再次儲存。啟用對應會攔截該裝置原始 HID 輸入。

可選操作包含巡航加／減速、10 單位調整、跟車距離、駕駛模式、LFA、車道線模式、左／右變換車道、撥片減速、CarrotCruise 與取消巡航。實體方向燈功能僅適用支援的 Jetson USB-CAN／B1 車輛。是否能執行仍取決於既有車型支援、輔助狀態、速度、盲點與轉向條件。

連按兩下的放開間隔為 350 毫秒；指定該功能後，短按會等待相同時間。長按於持續按住 700 毫秒後執行；巡航加／減速隨後每 500 毫秒重複。放開、斷線或既有駕駛介入條件會停止重複。最多可保存 16 台裝置；測試只作用於選取裝置，其他已啟用裝置仍可能運作。頁面內亦提供完整時序、配對、測試與多裝置說明。

工具、備份與維護

「工具」提供車型、語言、網頁偏好、裝置資訊、Git 與系統維護等入口。切換網頁語言與切換車機語言分別生效；車機語言請選「中文（繁體）」並依提示重新啟動。Git 操作會影響車機程式版本，請先確認目前倉庫、分支及畫面提示，再執行對應動作。

備份用於匯出設定，還原時須選取正確檔案並確認結果。重新啟動、重建、校正重設、記錄刪除等工具會依原有確認與車輛狀態限制執行。重建期間須等待建置完成；繁中化與滑動最佳化本身不變更車輛控制參數。

終端與遠端協助

終端頁可查看並操作既有終端工作階段。遠端分享由擁有者建立工作階段，對方使用分享網址與 PIN 連線。可分別設定僅查看、逐條核准或完整控制；逐條核准的指令有有效期限，拒絕或逾期不會執行。擁有者未查看終端時，頁面會顯示對應狀態。遠端客戶端可依瀏覽器或儲存語言顯示繁體中文。

車機滑動與故障復原

C3X 與 C4 共用文字排版快取：捲動只改變位置時沿用排版，內容、寬度或字型改變時重新計算；換行快取最多保留 1024 筆。此修改減少重複文字量測與表情符號解析，沒有變更駕駛控制迴圈。已完成桌面測試，尚未量測 C3X／C4 的實機幀率。

更新後請在安全停車時比較功能設定、網路清單、長說明與返回手勢。若仍卡頓，記錄頁面、裝置型號、是否行車中、是否開啟影像／回放／除錯資訊及時間，才能進一步區分繪圖、觸控或系統負載。啟動失敗的復原畫面也會依裝置繁中語言設定顯示繁體中文，原始錯誤與診斷內容仍保留。
