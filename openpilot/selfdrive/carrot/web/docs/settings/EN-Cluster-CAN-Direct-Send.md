## Cluster CAN Direct Send

`HyundaiCanfdClusterDirectTx`

For Hyundai/Kia/Genesis CAN-FD CameraSCC vehicles with intermittent cluster warnings, enable this to compare the original direct-send method for cluster messages. Defaults to OFF for every vehicle. Reboot the device after changing it.
