<!-- CARROT:SECTION:BEGIN BEHAVIOR -->
### 行为

设置视觉弯道和路线转弯的目标速度下限。视觉控制先将下限应用于弯道目标，再根据剩余距离计算当前接近速度上限。

- **调高:** 即使急弯也不会选择低于更高下限的目标。
- **调低:** 允许更低的弯道目标速度。
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 使用

需要目标速度下限时，与弯道调节比例分开调整。
<!-- CARROT:SECTION:END USAGE -->

<!-- CARROT:SECTION:BEGIN REFERENCE -->
### 参考

此值不保证道路上的安全速度。下限过高可能阻止必要的减速。
