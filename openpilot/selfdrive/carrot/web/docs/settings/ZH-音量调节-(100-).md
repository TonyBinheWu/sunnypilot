## 音量调节 (100%)

`SoundVolumeAdjust`

调节一般提示音的音量。DM 首次声音警告的增益至少为 70%，最终警告始终为 100%，不会因音量设置或环境噪声调节而降低。

### 行为

控制一般警告和提示音的音量倍率。 提高数值会增大一般提示音，降低数值会减小音量。

DM 首次声音警告的增益至少为 70%，最终警告始终为 100%，不会因音量设置或环境噪声调节而降低。该规则适用于模式 0 和 1，以及摄像头或操作监测。
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 使用

停车时播放提示音，分别确认语言、一般音量及启用和退出时的音量。

<!-- CARROT:SECTION:BEGIN REFERENCE -->
### 参考

声音警告之前的画面预警保持静音。使用相同音源的导航提示不适用 DM 音量规则。

百分比表示软件输出增益，并非实测扬声器声压。
