## 커브속도 조절비율(100%)

`AutoCurveSpeedFactor`

높이면 허용 횡가속도가 낮아져 커브 목표속도가 낮아집니다. 커브까지 남은 거리에 따라 미리 감속합니다.

<!-- CARROT:SECTION:BEGIN BEHAVIOR -->
### 동작

모델의 회전율과 같은 시점의 속도로 곡률을 구하고, 허용 횡가속도를 설정비율로 나누어 커브 목표속도를 계산합니다. 남은 거리에 따라 현재 위치의 속도 상한을 정하며 제어 응답과 점진적인 감속을 고려합니다.

- **높이면:** 같은 커브의 목표속도가 낮아집니다.
- **낮추면:** 같은 커브의 목표속도가 높아집니다.
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 사용

같은 커브에서 진입 전 목표속도와 통과속도를 비교하며 한 항목씩 조절합니다.
<!-- CARROT:SECTION:END USAGE -->

<!-- CARROT:SECTION:BEGIN REFERENCE -->
### 참고

모델의 먼 미래속도를 주행 목표로 직접 사용하지 않습니다. 예측이 늦으면 감속도 늦을 수 있으며, 회전이 완화된 새 모델 경로가 연속으로 확인되면 최근 약 0.25초의 가장 낮은 상한을 따라 vTurn을 빠르게 복구합니다. 더 강한 커브 제한은 즉시 적용하며, 같은 프레임의 반복이나 모델 입력 누락은 빠른 해제의 근거로 사용하지 않습니다. 실제 가속은 기존 가속도·저크 제한을 따릅니다.
