### 동작

버튼을 길게 눌렀을 때 기능이 작동하기 전까지의 지연 시간입니다.

- **값을 높이면:** 적용 시간 또는 지연 기준이 길어집니다.
- **값을 낮추면:** 적용 시간 또는 지연 기준이 짧아집니다.

폭스바겐의 별도 +·-에 적용합니다. 별도 SET·RES는 누른 시간과 관계없이 놓을 때 한 번만 처리하며 속도를 반복 증감하지 않습니다.
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 사용

버튼을 한 번 누를 때와 길게 누를 때 설정 속도가 변하는 폭과 시점을 확인합니다.
