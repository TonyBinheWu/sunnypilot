### 동작

- `-1` — 도로 제한속도가 바뀌면 새 제한속도 기반 목표로 바로 맞춥니다.
- `0` — 기존 크루즈 설정 속도를 유지합니다.
- `1`~`99` — 기존 설정 속도와 낮아진 새 제한속도를 비율로 섞습니다. 값이 높을수록 새 제한속도에 가깝습니다.
- `100` — 낮아진 새 제한속도를 그대로 적용합니다.
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 사용

도로 제한속도가 바뀌는 동일 구간에서 새 목표 속도와 속도 변경 시점을 확인합니다.
