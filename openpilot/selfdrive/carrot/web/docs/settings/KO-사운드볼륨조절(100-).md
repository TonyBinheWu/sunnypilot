## 사운드볼륨조절(100%)

`SoundVolumeAdjust`

일반 안내음의 음량을 조절합니다. DM 첫 경고음은 최소 70%, 마지막 경고음은 항상 100%로 출력되며 볼륨 설정이나 주변 소음에 의해 낮아지지 않습니다.

<!-- CARROT:SECTION:BEGIN BEHAVIOR -->
### 동작

일반 경고와 안내음에 적용되는 음량 배율입니다. 값을 높이면 일반 안내음이 커지고, 낮추면 작아집니다.

DM 첫 경고음은 최소 70%, 마지막 경고음은 항상 100%이며 볼륨 설정이나 주변 소음에 의해 낮아지지 않습니다. 0·1번 모드와 카메라·조작 기반 감시에 모두 적용합니다.
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 사용

정차 상태에서 안내음을 재생해 언어와 일반·인게이지 음량을 각각 확인합니다.
<!-- CARROT:SECTION:END USAGE -->

<!-- CARROT:SECTION:BEGIN REFERENCE -->
### 참고

경고음보다 앞선 화면 예고는 무음입니다. 같은 음원을 쓰는 내비게이션 안내에는 DM 음량 기준을 적용하지 않습니다.

백분율은 소프트웨어 출력 배율이며 실제 스피커 음압을 뜻하지 않습니다.
