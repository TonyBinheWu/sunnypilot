## 儀表 CAN 直接傳送

`HyundaiCanfdClusterDirectTx`

現代、起亞、捷尼賽思 CAN-FD CameraSCC 車輛出現間歇性儀表警告時，可開啟此項以對比原有的儀表訊息直接傳送方式。所有車輛預設關閉。更改後須重新啟動裝置。
