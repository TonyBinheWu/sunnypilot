## 차선변경 반응(100%)

`DynamicTFollowLC`

기본 TF를 유지하며, 정상 선택된 앞차의 실제 이탈과 거리 여유가 확인된 경우만 제한적으로 완화합니다. 차로 변경 시작 시 정상 선택된 leadOne/leadTwo를 기준으로 삼고, 진행 중 어느 앞차라도 바뀌거나 사라지면 해당 차로 변경이 끝날 때까지 추가 가속 완화를 중단합니다. 감속은 현재 정상 선택된 앞차만 사용하며, 옆쪽 레이더 후보나 시작 시점의 과거 차량을 별도 제동 대상으로 추가하지 않습니다. 100은 추가 완화 없음, 낮추면 완화량이 증가하며 80 이하는 같은 한도입니다. 최대 0.25초·4m입니다.

### 동작

차로 변경 시작 시 정상 선택된 leadOne/leadTwo를 기준으로 삼고, 진행 중 어느 앞차라도 바뀌거나 사라지면 해당 차로 변경이 끝날 때까지 추가 가속 완화를 중단합니다. 감속은 현재 정상 선택된 앞차만 사용하며, 옆쪽 레이더 후보나 시작 시점의 과거 차량을 별도 제동 대상으로 추가하지 않습니다.

값을 높이면 추가 완화량이 줄어들고 최대값에서 꺼집니다. 낮추면 확인된 이탈 이후 완화량이 증가하되 기존 상한을 넘지 않습니다.
