## 弯道速度调节比例(100%)

`AutoCurveSpeedFactor`

数值越高，允许的横向加速度和弯道目标速度越低。根据距弯道的距离提前减速。

### 行为

根据同一预测点的横摆角速度和速度计算曲率。设置比例用于调整允许的横向加速度，并根据距弯道的距离、控制响应和逐渐建立的减速确定当前速度上限。

- **调高:** 同一弯道的目标速度降低。
- **调低:** 同一弯道的目标速度升高。
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 使用

每次调整一项，比较同一弯道前的目标速度和通过速度。
<!-- CARROT:SECTION:END USAGE -->

<!-- CARROT:SECTION:BEGIN REFERENCE -->
### 参考

不直接把远期预测速度作为行驶目标。预测较晚时仍可能减速较晚；连续的新模型路径确认转弯趋缓后，vTurn 会快速恢复至最近约 0.25 秒内的最低上限。更严格的弯道限制立即生效；重复帧或缺失的模型输入不会触发快速解除。实际加速仍受现有加速度和加加速度限制。
